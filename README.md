# Bài Tập: Thiết Lập Màu Nền và Hình Ảnh Nền Trong CSS (CSS Background Practice)

Bài tập thực hành các thuộc tính nền trong CSS:
- `background-color: #f4f6f8`: Thiết lập màu nền toàn bộ trang web (`body`).
- `background-image`: Nhúng hình ảnh nền cho khối `.important-box`.
- `background-size: cover`: Đảm bảo hình nền bao phủ vừa vặn khung khối.
- `background-position: center`: Căn giữa tâm ảnh nền.
- `background-repeat: no-repeat`: Chống lặp ảnh.
- Căn giữa khối (`margin: 40px auto`) và căn giữa văn bản (`text-align: center`).
